# نسخة «الطريق إلى الرئيسي» (تجربة)

نسخة مستقلة من اللعبة للتجربة جنب اللعبة الأصلية. اللعبة الأصلية (`index.html` و`admin.html`) ما تغيّرت.

- اللعبة: `road.html`، والداشبورد: `admin-road.html`
- السيرفر: نفس مشروع Supabase، لكن كل الجداول والدوال نسخة بالبادئة `r_` (مثل `r_players` و`r_finish_game2`). المشترك فقط: `questions` و`admin_keys`.
- التخزين المحلي في المتصفح بالبادئة `rd_`، فما يختلط مع اللعبة الأصلية.
- منطق الرحلة: جدول `r_road` والدوال `r_road_state` و`r_road_after` (تُستدعى من `r_finish_game2`) و`r_mall_start`.

## القواعد
- 39 فرع + الفرع الرئيسي، على 6 محافظات. فوز في التحدي اليومي (بنقاط) = فرع للأمام. الخسارة ما ترجّعك.
- النجوم: فوز = ⭐، نتيجة 90+ = ⭐⭐، نتيجة 140+ = ⭐⭐⭐.
- سلسلة الأيام تنحسب من لعب التحدي اليومي. الدرع يحميها لو فاتك يوم واحد.
- صندوق عشوائي في نهاية كل محافظة: 100 أو 200 نقطة، أو درع + 50، أو نادراً (3%) 1500 نقطة.
- المولات (5) محطات اختيارية تنفتح بعد الفرع القريب منها، والدخول بمفتاح. الفوز = درع + 100 نقطة.
- كل 3 تدريبات = مفتاح (الحد الأقصى 5).

## إعادة التوليد
`road.html` و`admin-road.html` مولّدة من الأصل. لو تغيّر الأصل وتبي تنقل التعديل:

```
python3 tools/road/mkroad.py index.html road.html tools/road/road.css tools/road/road_page.html tools/road/road.js
python3 tools/road/mkadmin.py admin.html admin-road.html
```
